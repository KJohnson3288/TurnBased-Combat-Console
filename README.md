# Console RPG Combat System

A turn-based RPG combat system built in C# as a foundation for a future Unity project.

## Features

- Turn-based combat
- Character stats
- Damage calculation
- Critical hits
- Enemy encounters
- Extensible combat architecture

## Technologies

- C#

## Purpose

This project was created to practice object-oriented programming and gameplay system design before transitioning the combat system into Unity.

## Future Plans

- Port the combat system into Unity
- Add UI and animations
- Expand enemy AI
- Add abilities and status effects
